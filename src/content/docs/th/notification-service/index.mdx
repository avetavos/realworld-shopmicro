ตอบสนองต่อ domain event และแจ้งเตือนลูกค้าจาก consumer ของ Notification ที่แยกออกมาต่างหาก โดยไม่ผูกกับเซอร์วิสที่ผลิต event เหล่านั้น

เริ่มที่ [การรับ event →](/shopmicro/th/notification-service/consume-events/) แล้วไล่เรียนบทเรียนตามลำดับ (ดูที่แถบด้านข้าง)
