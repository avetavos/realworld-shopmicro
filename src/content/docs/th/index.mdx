## สิ่งที่คุณจะได้สร้าง

<CardGrid>
  <Card title="Introduction" icon="open-book">
    รู้จัก ShopMicro ว่าทำไมต้องสร้าง คอร์สนี้จัดโครงสร้างยังไง และสุดท้ายคุณจะได้อะไร [เปิดดู →](/shopmicro/th/introduction/)
  </Card>
  <Card title="Setup & Tooling" icon="setting">
    ติดตั้ง Go, Docker และเครื่องมือที่เหลือ พร้อมวางโครงสร้าง monorepo [เปิดดู →](/shopmicro/th/setup/)
  </Card>
  <Card title="Protobuf & gRPC" icon="puzzle">
    นิยาม contract ของเซอร์วิสด้วย Protobuf และ generate gRPC stub ของ Go [เปิดดู →](/shopmicro/th/proto-grpc/)
  </Card>
  <Card title="Catalog Service" icon="list-format">
    สร้าง gRPC server ของ Catalog ที่มี PostgreSQL เป็นฐานข้อมูลของตัวเอง [เปิดดู →](/shopmicro/th/catalog-service/)
  </Card>
  <Card title="Order Service" icon="list-format">
    สร้าง gRPC server ของ Order ที่สร้างคำสั่งซื้อและส่ง event ออกมา [เปิดดู →](/shopmicro/th/order-service/)
  </Card>
  <Card title="API Gateway" icon="server">
    เปิดเซอร์วิสให้เป็น REST ผ่าน grpc-gateway ภายใต้จุดเข้าเดียว [เปิดดู →](/shopmicro/th/gateway/)
  </Card>
  <Card title="Kafka (Event Stream)" icon="random">
    ส่งและรับ event log ที่ replay ได้ ด้วย producer และ consumer ของ Kafka [เปิดดู →](/shopmicro/th/kafka/)
  </Card>
  <Card title="RabbitMQ (Work Queues)" icon="bars">
    ส่งงานผ่าน exchange และ queue ของ RabbitMQ เพื่อประมวลผลแบบ asynchronous [เปิดดู →](/shopmicro/th/rabbitmq/)
  </Card>
  <Card title="Payment Service" icon="approve-check">
    รับ order event และประมวลผลการชำระเงินในเซอร์วิสเฉพาะทาง [เปิดดู →](/shopmicro/th/payment-service/)
  </Card>
  <Card title="Order Saga" icon="random">
    ประสานงานคำสั่งซื้อที่ข้ามหลายเซอร์วิสด้วย saga และ outbox pattern [เปิดดู →](/shopmicro/th/saga/)
  </Card>
  <Card title="Notification Service" icon="comment-alt">
    ตอบสนองต่อ domain event และแจ้งเตือนลูกค้าจาก consumer ที่แยกออกมา [เปิดดู →](/shopmicro/th/notification-service/)
  </Card>
  <Card title="Resilience" icon="warning">
    เพิ่ม timeout, retry และ backoff เพื่อให้ระบบทนต่อความล้มเหลวบางส่วนได้ [เปิดดู →](/shopmicro/th/resilience/)
  </Card>
  <Card title="Testing" icon="approve-check">
    คลุมทุกเซอร์วิสด้วย table-driven unit test และ integration test [เปิดดู →](/shopmicro/th/testing/)
  </Card>
  <Card title="Docker & Compose" icon="server">
    ทำ container ให้ทุกเซอร์วิส และรันทั้งสแตกด้วยคำสั่งเดียว [เปิดดู →](/shopmicro/th/docker/)
  </Card>
  <Card title="Kubernetes (Helm)" icon="cloud-download">
    แพ็กและ deploy ทั้งระบบขึ้น Kubernetes ด้วย Helm chart [เปิดดู →](/shopmicro/th/kubernetes/)
  </Card>
  <Card title="Wrap-up" icon="star">
    ทบทวนสิ่งที่คุณสร้างมา และก้าวต่อไปของ ShopMicro [เปิดดู →](/shopmicro/th/wrap-up/)
  </Card>
</CardGrid>
