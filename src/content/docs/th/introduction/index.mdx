ยินดีต้อนรับ ในคอร์สนี้คุณจะได้สร้าง **ShopMicro** ระบบ e-commerce แบบ microservices ที่ขับเคลื่อนด้วย event ด้วยภาษา Go ตั้งแต่ repo เปล่า ๆ ไปจนถึงการ deploy ขึ้น Kubernetes ด้วย Helm ทั้งห้าเซอร์วิส — API Gateway, Catalog, Order, Payment และ Notification — คุยกันแบบ synchronous ผ่าน gRPC (พร้อม REST ผ่าน grpc-gateway) และแบบ asynchronous ผ่าน Kafka และ RabbitMQ โดยแต่ละเซอร์วิสมี PostgreSQL เป็นของตัวเอง และเชื่อมทุกอย่างเข้าด้วยกันด้วย order saga ที่สร้างบน outbox pattern
